# 去远方 / Dream Journey

本地研学作品原型。按两张草图改为固定一屏：左侧可交互地球，右侧首页显示影响数据与自动轮播；点击地点后，右侧切换文字、图片、3D作品页。页面固定一屏；文字在右侧单一文章中上下滚动，照片逐张切换。仅面向电脑端，不制作手机布局。

## 运行

需要 Node.js 22.16+。页面和API由同一个Node服务提供，默认地址 http://127.0.0.1:8765/ 。

```sh
npm ci
npm start
```

将 `.env.example` 复制为 `.env` 后，可填写服务端 `DEEPSEEK_API_KEY`。密钥不进入前端；没有密钥时明确提示配置未完成，仍可手动填写并发布。修改环境配置后重启服务。

## 账号、上传与发布

- 未登录是访客，只显示“登录”；注册可选择捐赠者或教师。角色选择沿用1.0的自选方式，不代表教师资质认证。
- 只有教师登录后才显示“上传”。服务端也校验会话与权限：访客不能写入，捐赠者不能上传、分析或发布。
- 支持 PDF、Word、Excel、PPT、TXT/Markdown/JSON、图片、ZIP 和 GLB。单次最多10个文件、单文件8MB、合计20MB；ZIP展开后仍须符合限制。
- 教师上传资料，可交由DeepSeek整理成双语草稿；检查来源、补充内容、设置文件用途后再发布。也可直接手工填写。
- 发布后的资料使用当前左地球/右内容界面展示。文字和附件在Notes中，照片在图片页，所上传GLB在3D页；没有模型的项目显示空态。
- “旅行手记”可查看全部项目；无坐标的项目不强行标点，同地点项目可通过地图点选择。
- 账号、密码哈希、会话及项目保存在 `storage/`（或 `JOURNEY_DATA_DIR`），服务重启后仍保留。不要删除该目录；部署需持久化磁盘。
- `.env` 和 `storage/` 均已忽略，不打包进静态页面。单独的GitHub Pages只能承载前端，完整功能需要Node后台。

## 内容与来源

- `src/js/data.js` 保留四项目封面、城市位置和原始空字段。
- `src/js/journey-content.js` 为实际展示内容：土楼时间线依据根目录《资料.docx》，其余依据 `hackthon photos.zip` 内的研学手抄报整理。图片存放 `assets/photos/`，标注手抄报、采访记录或作品照片，未冒充现场摄影。
- 苏州按要求改为油纸伞主题，补写内容明确标为示例，不当作真实行程；敦煌手抄报中的目标/地点清单不等同完成行程；苗族资料按主题汇集。
- `src/js/impact-data.js` 引用真爱梦想基金会官方微公益项目披露 https://gongyi.weibo.com/r/239643 ，统一截至2025年：超过18,000名孩子与老师、3,600多支队伍、队伍来自30个省市区。地区数不是到访目的地数量。
- 地球恢复最初的绿色简笔画风格，采用本地 Three.js 和简化全球轮廓，无省市文字。可自由左右旋转、缩放，只标注四个项目点。
- `src/js/project-models.js` 按用户指定关联作品：苏州展示梅花油纸伞，贵州（贵阳）展示土楼纸艺模型（现有村庄GLB）；漳州和敦煌显示“暂无3D作品”。原始 `.blend` 不变。

## 交互

- 地球拖动、滚轮/按钮缩放、键盘方向键移动，Home复位；点击地图项目点或名字打开手记。
- 首页相册仅显示图片，每5秒自动切换；不显示标题、图注、地点标签、翻页按钮或纸张装饰。弹窗打开或页面不在前台时暂停。
- 文字合并一页内部滚动、图片切换并可放大；3D模型按需加载，拖动旋转、滚轮缩放及恢复视角。
- 中英切换保留项目与地图位置，原始项目材料保留中文。
- 右上角“登录”支持注册、登录和退出；教师登录后显示“上传”。
- 返回/前进和 `#journey/tulou` 等直接链接可用。WebGL不可用时地图项目点降级为可点击的地点列表。

## 校验

```sh
npm run check
npm test
```

`tests/browser.html` 为本地浏览器交互验收入口。已整合1.0的Node后台；源 Blender 工程保持不变。作品查看器的 Three.js 与对应 addons 使用0.180.0；地球同样使用本地 Three.js，均不依赖远程运行库。


## 整合验收

`tests/browser.html` 验证原有地球、文字、照片、模型及布局。`tests/integration-browser.html` 仅允许本机8767端口，并需独立临时 `JOURNEY_DATA_DIR`；会创建测试账号与项目，不能连接正式存储。它验证注册、角色权限、上传、审核发布、刷新恢复和访客访问，不调用真实DeepSeek。
